# Module Ownership

The six major ownership areas are:

1. **Product Media Intelligence** — image input handling, media quality and
   readiness analysis, and image-related schema output.
2. **Voice & Language Intelligence** — voice input, transcription, language
   handling, translation, and voice-related schema output.
3. **Pricing Intelligence** — cost interpretation, pricing reasoning, market
   references, confidence, and pricing-related schema output.
4. **Catalogue/Product UX** — catalogue content and product presentation
   requirements, without implementing the mobile frontend in this foundation.
5. **Dataset/Evaluation** — approved datasets, evaluation criteria, test data,
   and measurement of module quality.
6. **Frontend/UI & Integration Testing** — future client integration, user
   flows, and cross-module integration tests.

No personal names are assigned here. Team members should agree on names and
sub-ownership separately.

**TEAM RULE:** Each member works primarily within their assigned module/code
section. Nobody should modify, restructure, rename, or overwrite another
teammate's module without coordination. If an integration change affects
another module, coordinate with its owner first.
